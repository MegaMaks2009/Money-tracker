# Money tracker
A simple program for tracking how much money you've spent or earned. It creates a graph and saves your progress.

## How to install?
1. Download the project.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the program:
   `python main.py`

## How to use?
1. Right-click on the graph to add a transaction.
2. Enter the amount using `+` for income or `-` for expenses.
3. Optionally, add a note about the transaction.
4. Press `Enter` to save it.
5. Use the mouse wheel to zoom in or out.
6. Hold the left mouse button and drag to move around the graph.
7. Press `Ctrl+Z` to undo the last transaction.
